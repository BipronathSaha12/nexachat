# NexaChat

Welcome to **NexaChat**, a modern, responsive, and accessible AI chatbot interface.

This repository is split into two main parts:
- **Frontend**: A React application powered by Vite, providing a seamless and highly responsive user experience with markdown and code block support.
- **Backend**: A Python-based server that handles API requests, streaming responses, and business logic.

## Documentation

Please refer to the specific documentation files for instructions on setting up and running each part of the stack:

- 📖 [Frontend Documentation](frontend.md)
- 📖 [Backend Documentation](backend.md)

## Accessibility First
NexaChat is built with accessibility in mind, ensuring high contrast ratios and proper document heading structures, validated via Axe DevTools.
